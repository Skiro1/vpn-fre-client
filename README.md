# VPN Client

Десктопное приложение для Windows с графическим интерфейсом. Объединяет Opera Proxy и Cloudflare WARP (AmneziaWG) в одном окне.

## Возможности

- **Opera Proxy** — HTTP-прокси с выбором региона (Европа, Азия, Америка). Автоматически получает список серверов, подключается и настраивает системный прокси.
- **Cloudflare WARP** — генерация конфига WARP через warp-awg-gen и подключение через AmneziaWG.
- **Пинг** — TCP-пинг до серверов Opera Proxy с отображением задержки в реальном времени. Работает через файрволы (не ICMP).
- **Автообновление** — при отсутствии бинарников скачивает их из GitHub Releases.
- **Автоустановка AmneziaWG** — если драйвер не найден, предлагает скачать MSI и установить.
- **Экстренный сброс** — останавливает все процессы и сбрасывает системный прокси.

## Требования

- Windows 10/11 (64-bit)
- Python 3.10+ (для сборки из исходников)

## Сборка .exe

### Debug (с консолью)

```
build_debug.bat
```

### Release (без консоли)

```
build_release.bat
```

Готовые .exe появятся в папке `dist/`.

## Запуск из исходников

```
python vpn_client.py
```

Параметр `--debug` включает вывод лога в консоль.
